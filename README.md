# Robot Agent Lab — a lab's overnight shift, run by an agent team you can walk away from

**Recursive Agents Hackathon · Crusoe × Cerebral Valley · Oct 17, 2026 · Track: Shared Brain (with Done Means Done built in)**

Sample tubes arrive all day with coloured caps. Before the night runs someone has to put each tube where it belongs:
red caps to the cold rack, blue caps to the sequencer rack, green controls stay on the bench. A tube in the wrong rack
ruins a run that costs more than the robot. We replace the technician's night shift with a team of Nemotron agents on a
simulated SO-101 arm. The human types one line, **"Put tonight's samples where they belong."**, and leaves.

Every agent reads a **shared, time-versioned brain** before its shift and writes back after. A **sealed camera verifier**
decides what "done" means. The claim we prove with numbers: **shift four is cheaper and more honest than shift one.**

## The four things the system does

| | What | Where | How we know it works |
|---|---|---|---|
| **1. Collaborate through shared memory** | every agent reads the brain before its shift and the curator writes deltas after; facts carry provenance and validity windows, and a changed value supersedes the old one | `brain/ledger.py`, `agents/team.py::curate`, `auto_facts` | with-brain vs no-brain table on identical seeds; stale-fact servings after the rack moves |
| **2. Independently verify their work** | a sealed verifier that sees only the checks and a top-down photo, never the operator; the operator's done claim is diffed against the tool log and must cite evidence per check | `team.py::verify`, `claim_vs_trace` | verifier accuracy measured against sim ground truth; false-done claims caught |
| **3. Detect failures** | rule-based monitor: exact-repeat loops, observe-only stalls, progress-interval collapse, infeasible flag, budget, camera down → `continue / replan / stop / ping` | `team.py::Monitor` | every decision and its reason is logged per shift |
| **4. Improve their outputs autonomously** | the improver rewrites the operator playbook from shift history and the change is **kept only if it scores at least as well on a held-out seed** the team has never run | `improve.py`, `runs/playbook.json` | before/after score on the held-out shift, with the version history |

## What is in the loop

| Agent | Model (Crusoe Managed Inference) | Job |
|---|---|---|
| Planner | `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B` | turns the one-line goal into a definition of done the team can verify without the human |
| Operator | `nvidia/Nemotron-3.5-Lightning-30B-A3B` | drives the arm through five tools; ends every message with an honest progress interval; cites evidence for every check in its done claim |
| Verifier | `nvidia/Nemotron-3-Nano-Omni-Reasoning-30B-A3B` | **sealed**: sees only the checks and one top-down photo, never the operator; 3 samples, majority vote |
| Monitor | rules + `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` | loop detection, progress collapse, budget, camera-down → `continue / replan / stop / ping` |
| Curator | `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` | after each shift, writes itemised deltas to the brain, never a rewrite |

**Shared brain** (`brain/ledger.py`): a SQLite ledger of `(subject, relation, object)` triples with `valid_from / valid_to`,
provenance (`source_agent, episode, evidence_ref`) and helpful/harmful votes. A new value for the same subject+relation
**supersedes** the old one deterministically; nothing is deleted. Retrieval = relevance × decay × usefulness.

**Bench** (`sim/`): MuJoCo, SO-101 arm from MuJoCo Menagerie, three 2 cm tubes, two rack patches, a top-down operator
camera with a colour-centroid detector, a separate verifier camera. Three injected quirks the brain has to learn:
a gripper that only closes on the second command, a rack that moves on shift 3, a camera nudged 3 cm on shift 5.
Ground truth comes from the sim and is used only by the eval, which means we can also report **the verifier's own accuracy**.

## Results

**Shared brain vs no brain**: see `eval/report.md` (generated by `python -m eval.report_from_runs`). Same seeds, models and prompts in both arms.

Reading of the 4-vs-4 run on the final bench (standing tubes): both arms placed the tubes correctly in 1 of 4 shifts. The sealed verifier was right in all 8 shifts against ground truth and caught every false "done" (1 without memory, 2 with). With memory, shift 1 succeeded and wrote the gripper lesson; at shift 3 the blue rack moved and the old position row was superseded the same shift, with 0 stale positions served afterwards. Memory has not yet raised the success rate or cut tool calls: the operator works from camera coordinates and the gripper quirk costs a retry on every pick, so most shifts run out of budget. An earlier run on a cube bench reached 3 of 4 in both arms; the cylinder tubes are harder to place. We report the run that matches the shipped bench.

**Version N+1, one cycle (held-out seed 500, never run before)**. The improver read four no-brain shifts and proposed a six-rule operator playbook. Gate: one shift with the old playbook, one with the new, same seed, no brain.

| | Old (v0, no playbook) | New (v1) |
|---|---|---|
| Success | no | no |
| False "done" claim | **yes** | no |
| Tool calls | 23 | 45 |
| Score | -61.5 | -22.5 |

Kept as v1: it removed the false completion at the cost of more calls and an unfinished shift. The next cycle sees that record and has to earn its keep against v1. History with every proposed rule set and both scores is in `runs/playbook.json` (`improve.py --history runs/brain --seed 501` runs the next cycle).

What the first live shifts looked like, before any fixes: the no-brain operator got `holding: null` from the sticky gripper, lifted nothing, "placed" nothing, and then looped between park and look until the monitor stopped it. With the brain on, the first shift claimed done with nothing racked and the sealed verifier failed it; the curator wrote the gripper quirk and the rack positions, and shift two succeeded.

## Run it

```bash
uv sync
export CRUSOE_API_KEY='...'                      # single quotes; keys can contain $
uv run python -m llm.crusoe models               # confirm model ids against /v1/models
uv run python tests/test_scripted.py             # the bench, no LLM: reach, grasp, sort, sticky gripper, frames
uv run python run_episode.py --episode 1 --no-brain
uv run python run_episode.py --episode 1         # with brain (runs/brain.sqlite)
uv run python -m eval.run_sweep --episodes 8     # the table
uv run python run_episode.py --episode 9 --camera-down   # the one time it pings a human
```

## Sponsors in the build

- **Crusoe Managed Inference**: every call. We log `usage.prompt_tokens_details.cached_tokens` per call; at event time the endpoint returned no cache details for the Nemotron models, so the cached-token column reads 0 and we do not claim a cache saving.
- **NVIDIA Nemotron**: all five roles; Nano Omni is the only agent that *looks*.
- **NVIDIA NemoClaw / OpenShell**: the operator is the only agent that executes generated motion code, so it runs in an OpenShell sandbox whose network policy allows one host (`nemoclaw/policy.yaml`).
- **You.com**: `research(question)` is a tool the operator can call when something is outside the protocol (`agents/researcher.py`, You.com Search API). Answers come back as cited snippets with a retrieval date, so the curator can store them as sourced facts.

## Disclosure (new work only)

All code in this repository was written during the hackathon on Oct 17, 2026. The **idea** that stale memories should lose
at retrieval time rather than be deleted comes from two earlier projects by the same author (Travel-Companion, "Superseded");
no code from them is used here. The SO-101 model is from MuJoCo Menagerie (Apache-2.0, DeepMind), vendored unchanged in
`sim/so101/`. No physical hardware was used.
